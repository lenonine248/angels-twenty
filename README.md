# ANGELS TWENTY

**Beta 1**（2026-08-20）

**▶ [ブラウザで遊ぶ](https://lenonine248.github.io/angels-twenty/)**

戦闘機による空戦／対地を題材にした、ブラウザで動作するリアルタイム戦略シミュレーション。

3Dソリッド（ローポリ・フラットシェーディング）のフィールドを斜め上から見下ろしながら、
自軍戦闘機に指示を出してステージ目標を達成する。プレイヤーは操縦せず、指揮する。

- 更新履歴: [CHANGELOG.md](CHANGELOG.md)（タイトル画面の版表示をクリックするとゲーム内でも読める）
- 仕様書: [docs/SPEC.md](docs/SPEC.md)
- 現在地・調整箇所・残課題: [docs/STATUS.md](docs/STATUS.md)
- 依存: Three.js r160（`vendor/` にローカル同梱・CDN不使用）／ビルド不要

## 起動方法

公開版は <https://lenonine248.github.io/angels-twenty/> でそのまま遊べる。
以下はローカルで開発・改造する場合の手順。

ES Modules を使うため、ローカルサーバー経由で開く。

```bash
python D:/Claude_workspace/angels_twenty/devserver.py 8187
```

その後 <http://localhost:8187/> を開く。
Windows では `start_server.bat` をダブルクリックしても起動する。

`devserver.py` は no-store を返すだけの静的サーバー。`python -m http.server` だと
ブラウザが ES モジュールをキャッシュし、ソースを直しても古いモジュールが
読み込まれ続けることがあるため用意している。

## 遊び方

タイトル → ミッション選択 → ブリーフィング（目標・戦域図・兵装編成）→ 出撃 → 戦果。
クリアすると次のミッションが解禁され、`localStorage` に保存される。

**ユニットの操作**

| 操作 | 動作 |
|---|---|
| 左クリック | 選択（Ctrl/Shift+クリックで追加選択） |
| 左ドラッグ | 範囲選択 |
| 右クリック（地面） | その地点へ移動 |
| 右クリック（敵） | 攻撃。兵装を選択中ならその兵装での**射撃指示**（攻撃目標は変えない） |
| 右クリック（味方機） | 随伴 |
| Shift+右クリック | 経路を追加（ウェイポイント） |
| Z / X | 目標高度を 500m 下げる／上げる |
| C | 選択機を画面中央へ |
| Tab | 次の機体を選択 |
| B | 最寄りの自軍飛行場へ帰投 |
| G / Shift+G | 編隊を組む（最大4機・自動で連携モード）／解散 |
| Ctrl+数字 / 数字 | 編隊の登録／呼び出し |
| Esc | 選択解除。**未選択なら一時停止してメニュー** |
| ロースター行クリック | 選択（ダブルクリックで追跡） |

**詳細パネルでできること**

- AIモードの切替（哨戒／追撃／連携／回避優先／護衛／対地攻撃）
- 目標高度のプリセット（各高度での推力・旋回率を併記）
- 兵装をクリックして**使用兵装を指定**（射程円が表示される）
- 兵装ごとの**自動使用 ON/OFF**（高価な兵装の温存）
- **自動発射のしきい値**（低／中／高）— 命中期待度がこれを下回るとAIは撃たない
- **誘導中も回避／誘導を優先**（AAM-M のクランク中に被弾リスクを取るか）
- 駐機中は兵装の積み替えと発進

## 設計上の要点

- **すべてメートル単位**。マップは 51.2km 四方、地形は 200m グリッドのハイトマップ。
- **地形は固定シードから生成**する。同じステージなら毎回まったく同じ地形になるため、
  ブリーフィングでの地形読みが成立する。
- **シミュレーションは固定タイムステップ（1/30秒）**。倍速は1フレームあたりの
  ステップ数を増やして実現しており、再現性を保っている。
- **地形の視線判定 `Terrain.hasLineOfSight()`** がレーダー・目視・ミサイルシーカーの
  共通基盤になる。低空飛行で山陰に隠れる、という戦術はここに集約される。
- **地形回避は「これから通る経路」を先読みする**。旋回を織り込んだ予測経路を150m刻みで
  サンプルしないと、サンプルの隙間の尾根に突っ込む（実際に起きた）。
- **機影は画面上で一定サイズになるよう誇張表示**する。実寸15mでは51kmのマップ上で
  1px未満になり、選択も識別もできない（`world/models.js` の `aircraftDisplayLength`）。
- **カメラの注視点は「地表＋注目高度」**。地面を注視すると高度3kmの機体が画面外に出る。
  注目高度は選択機の対地高度に追従する。
- **探知は陣営ごとの Contact として持つ**。画面に出るのは「こちらが把握している情報」であって
  真の配置ではない。ミニマップもコンタクト経由で描く。
- **敵の実体メッシュを描くのは「識別済み＋現在探知中＋位置が精密」のときだけ**。
  電波逆探知だけで捕まえた目標は位置が±1km粗いため、実体を描くと誤差が意味を失う。
- **全走査は5Hz**。毎フレーム回すと視線判定が重い。走査間はデッドレコニングで補間する。
- **ミサイルの命中判定は「最接近を通過した時点」で行う**。近接信管圏に入った最初の
  フレームで起爆させると、必ず信管半径ちょうどの距離で爆発して永遠に至近弾になる。
- **ミサイルの減速量は設計速度に比例させる**。固定値にすると低速な対地ミサイル(320m/s)が
  数秒で失速し、射程の半分も飛べない。射程の限界は「燃焼後に速度をどこまで保てるか」で
  自然に決まる設計にしてある。
- **地上目標への視線判定は目標を40m持ち上げて行う**。地上目標は地表にいるため、
  その一点を狙うと着弾直前に必ず「地形に遮蔽されている」と判定されてしまう。
- **無誘導爆弾の投下点は弾道解で決める**。機首の指向角で判定すると、水平飛行中は
  目標が常に下方にあるため永久に投下できない。投下窓は爆風半径より狭くしないと当たらない。
- **高度による性能変化は `core/atmosphere.js` に集約**する。ジェットは高空で推力・旋回が
  落ち、ロケット（ミサイル）は抵抗が減って射程が伸びる。高度そのものが射程を買う手段になる。
- **降下中は減速の権限を絞る**（推力の15%まで）。これが無いと降下しても巡航速度まで
  落ちてしまい、位置エネルギーを速度に変える一撃離脱が成立しない。
- **飛行場は設置時に滑走路帯を整地する**（`Terrain.flattenStrip`）。平坦地を選ぶだけでは
  滑走路脇の起伏に降着してしまい着陸できない。進入路を滑走路より高く均すのは厳禁
  （接地点が持ち上がって永久に降りられなくなる）。
- **離着陸は通常の飛行処理を通さない**。通常処理は最低対地高度220mを確保するため、
  そのままでは着陸できず、離陸直後は地形衝突判定（地表+20m）で即墜落する。
- **整備は「作業の列」として持つ**。燃料→兵装→機銃/デコイ→修理の順に並べ、
  完了した分から反映する。これで「燃料だけ入れて即発進」という部分補給が成立する。
- **SAM の実効射程は目標高度を重く見る**（発射点0.3 : 目標0.7）。地上発射は飛翔の
  ほとんどが上空なので、単純平均だと高空目標への優位が出ない。
- **SAM は ARM の飛来に反応時間（2.5秒）を置いてから沈黙する**。即座に沈黙させると
  ARM が絶対に当たらなくなり、SEAD が成立しない。気づくのが遅ければそのまま食らう。
- **AIは飛び方を直接いじらず「指示(order)」を出す**。飛行・回避・地形回避は
  `sim/aircraft.js` が一貫して持つので、AIの指示と手動の指示が同じ仕組みに乗る。
- **目標の重複回避は同一tick内でカウントを更新する**。tick開始時のスナップショットだけを
  見ると、編隊の全機が「まだ誰も向かっていない」と判断して同じ敵に殺到する。
- **ミッションの勝敗は内部の真の状態で判定する**。目標が視界外で破壊されても、
  条件を満たしていればクリアになる（画面上は「状態不明」のままでも達成扱い）。
- **輸送機のような支援機には TRANSIT モードを使う**。回避優先(EVADE)にすると
  経路を捨てて敵から逃げ続け、目的地に着かない。
- **HUDは「構造」と「数値」を分けて描く**。パネル全体を毎回 innerHTML で作り直すと、
  カーソルを合わせているボタンが作り直されて :hover が点滅し、クリック判定も安定しない。
  構造は内容が変わったときだけ作り直し、数値はキャッシュした要素へ書き込む。
- **機首の向きは -Z**。X軸まわりの正回転で機首が上がるので、上昇(pitch>0)には
  そのままの符号を渡す（符号を反転すると上下が逆になる）。
- **AIの目標選択にはヒステリシスを入れる**。敵が固まっていると距離の僅差で
  最適目標が入れ替わり、毎tick目標を変えて機首を振り回す。現在の目標に下駄を
  履かせ、乗り換えの最短間隔も設ける（実測: 密集した敵3機に対し90秒間の変更0回）。
- **帰投先が無い機体は燃料切れで落とさない**。マップ外を拠点とする敵編隊が
  勝手に落ちると、戦果が転がり込むだけで面白くない。
  ただし**そのまま放置すると縁を延々と飛び続け、「全機撃墜」の目標が永久に達成できない**。
  帰投判断か燃料切れで縁の外へ向かわせ、マップ外3kmで戦域から取り除く（撃退扱い）。
- **命中期待度は静止目標と空中目標で式を分ける**。回避しない相手に空対空と同じ
  距離減点をかけると、SAM の射程外から撃つための ARM が「当たらない」と判定されて
  永久に撃てず、結局 SAM の懐まで近づく羽目になる。静止目標では「当たるか」ではなく
  **弾が届くか**だけを見る。
- **ミサイルの速度は「表記射程まで実際に届くか」で決める**。慣性飛行の距離は速度に
  比例するので、遅すぎると発射エンベロープの縁に届かない。実際 ARM(520m/s) は
  高度5,000mから22.2kmしか飛べず、21.9kmで撃った弾が目標手前で失速していた。
  `speed` を触ったら実飛翔距離を測り直すこと（[STATUS.md](docs/STATUS.md) に表がある）。
- **ARM は沈黙されても最後の座標へ慣性で向かう**。「沈黙＝必ず外れる」にすると
  SAM は 2.5秒で沈黙できるので ARM は理屈のうえで一度も当たらない兵装になる。
  逆に「必ず当たる」だと相手は静止目標なので沈黙が無意味になる。
  誤差を残距離に比例させ、気づくのが遅いほど食らうようにしてある。
- **SEAD 機は SAM 圏でも降下させない**。低空退避は AGM 機のための行動で、
  最低発射高度2,500mの ARM を積んだ機体を降ろすと一度も撃てないまま突っ込む。
- **音の耳はカメラではなく注視点**。RTS視点ではカメラは常に十数km離れているため、
  カメラ位置を耳にすると画面中央で起きたことまで遠くの音になる。
  減衰の基準距離はズーム量に比例させ、引くと広く薄く聞こえるようにしている。
- **警報は「見つかっている」ではなく「撃たれうる距離」で鳴らす**。探知されただけで
  鳴らすと、開始から終了まで警報が鳴りっぱなしになる。
- **粒子は2つの Points にまとめ、大きさはピクセルで指定する**。個別メッシュにすると
  乱戦で数百ドローコールになり、実寸指定だとズームで消えたり画面を覆ったりする。
- **一時停止中は演出も止める**。煙だけが流れ続けると止まって見えない。
  ただし粒子の初期不透明度を0にすると、停止中に発生した煙が見えないままになる。
- **「誘導を優先」の判定は指示の種類で見てはいけない**。最後の1発を撃った瞬間に
  「兵装を撃ち尽くした」判定で帰投指示へ切り替わり、`order.type` が attack でなくなった
  途端に回避を始めて、まさに今誘導している弾を自分で外してしまう。
  自分が誘導中の弾があるかで判定し、そのあいだは弾切れ帰投も保留する。
- **BGM は超低域に置かない**。30Hz台は多くのスピーカーで再生されず、
  音量計だけが振れて実際には何も聞こえない。聞こえる帯域に置いてそのぶん小さく鳴らす。
- **エンジン音とBGMは効果音より一段下げる**。常時鳴っている音なので、
  大きいと爆発もミサイル警報も埋もれる。
- **プレイ記録はファイルにも落とす**。localStorage はブラウザのプロファイルと
  オリジンに閉じていて開発側から読めない。難易度調整の材料にするには
  ファイルに残っている必要があるので、開発サーバーへ送って `playlog.jsonl` に追記する。
- **更新履歴はゲーム内用に別データを持たない**。`CHANGELOG.md` をそのまま読んで
  組み立てる。表示用のデータを別に置くと、必ず片方だけ更新されて食い違う。
- **ブリーフィングの搭載はステージごとに記憶する**。出撃 → 途中でブリーフィングに戻る、
  を繰り返すたびに組み直しになると煩わしい。
- **指令高度は平滑化して渡す（上げる方向は即座に）**。地形先読みも回避も
  目標高度が毎フレーム揺れるので、生の値を渡すと機首が上下に振動する。
  上昇率の大きい機種ほど激しく振れ、爆弾の投下条件が揃わなくなる。
  ただし上げる方向を遅らせてはいけない（地形回避が間に合わなくなる）。
- **回避の指令に段差を作らない**。「残り8秒未満なら全力降下、そうでなければ維持」の
  ように切り替えると、ミサイルの機動でしきい値をまたぐたびに上下に暴れる。
  残り時間に対して連続に変化させる。回避方向も一度決めたら脅威が消えるまで保つ。
- **敵機の既定搭載は機種の役割から決める**。一律で空対空を積むと、
  爆撃機が爆弾を1発も持たずに目標上空へ飛んで対空砲に落ちるだけになる。
- **編隊の速度制御は符号付きの前後ズレで見る**。目標までの距離（符号なし）で
  速度を決めると、追い越したあとも「離れている」と判断して加速し続け、
  護衛機が被護衛機を永久に追い越す。
- **地形回避は「登り切れるか」で判断する**。先読み距離を上昇率から決め、
  間に合わない針路は避けて減速する。高度を上げる指示を出すだけでは、
  上昇率の低い機体が急峻な尾根に対して物理的に間に合わない。
- **難易度の軸に「撃つ判断のしきい値」を使ってはいけない**。ミサイルが実体で飛ぶため、
  しきい値を下げれば手数が増えて強くなり、上げれば良い射点でだけ撃つので強くなる。
  どちらへ動かしても強くなるので軸にならない。練度は発射間隔・照準精度・反応速度・
  回避の質といった**単調に効く軸**だけに効かせる。
- **AIだけで自動周回させる検証台を用意した**（`tools/bench.js`）。難易度の微調整より、
  「詰み」や「絶対に当たらない兵装」のような構造的な不具合を見つけるのに効く。
  上の3件（戦域離脱・静止目標の命中期待度・ミサイル速度）はすべてこれで発見した。
