## 2. 作る前に測ること

振る舞いの候補 4つが**どれだけ効くか・既存の AI とかぶっていないか**を先に測る。

- **既存の規則が既にやっていないかを先に見る**（memory: existing rules answer the threat）。
  デコイ（`DECOY_TTI_EARLY/LATE`）・ブレイク（`acm.js`）・撃つ判断のしきい値は既にある。
  「上手くする」の伸びしろがどれだけ残っているかを、条件を強制して測る（memory: measure the truth, not the AI）
- **種を固定して A/B**（memory: fix seed for AB）。並の敵 1機 vs 同じ敵にその振る舞いだけを足した 1機を、
  自軍の AI（練度 1）と当てる。1対1 と 2対2
- **結末ごとに割って並べる**（memory: split outcomes by category）。エースの被撃墜率だけでなく、
  自軍の損失・エースが撃った数と当てた数・交戦時間・離脱した回数も出す（memory: bench sees outcome, not play）
- **プレイヤーが相手のときに見て分かるか**も見る。数字が効いていても、画面で違いが見えないものは得意技にならない

測った結果で上位3つを選び、E4 の 3人に割り当てる。
